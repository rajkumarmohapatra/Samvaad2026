# SAMBAD 360

Microsoft-first event management foundation for Sambad, using SharePoint, Power Apps, Power Automate and Power BI.

The implementation foundation, setup workbook, and synthetic acceptance workbench are being added through a review branch. Microsoft 365 deployment requires tenant configuration and acceptance testing; this repository does not represent a deployed production application.

Only source, documentation, templates, and synthetic samples belong in this repository. Never commit real participant, banking, identity, health, credential, or access-token data.
